JRA Odds Backup

JRA Odds Backup is a personal backup system used by its developer to store archived horse-racing odds data in the developer's own Google Drive account.

The system uses rclone and the Google Drive API to upload, store, and verify backup archive files.

This application is for personal use only. It is not provided as a public service and is not intended for use by third parties.

Google Drive access is used solely for storing, reading, and verifying the developer's own backup files.

本システムではrcloneおよびGoogle Drive APIを利用し、 バックアップファイルのアップロード、保存、読み取り、 整合性確認を行います。
