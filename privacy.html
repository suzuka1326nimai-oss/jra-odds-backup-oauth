Privacy Policy / プライバシーポリシー

Last updated: September 23, 2026

1. About this application

JRA Odds Backup is a personal system used solely by its developer to back up developer-owned data to the developer's own Google Drive account.

This application is not offered as a public service and is not intended for use by third parties.

2. Access to Google user data

This application uses OAuth 2.0 and the Google Drive API. Google Drive access is used only for operations necessary to store, read, verify, and manage the developer's own backup files.

3. Use of Google user data

Google Drive access is used for the following purposes:

  • Uploading backup archive files
  • Reading stored backup files
  • Verifying backup file integrity
  • Managing files required for the backup process

Google user data is not used for advertising, marketing, profiling, analytics, or any unrelated purpose.

4. Data storage

Backup data is stored only in environments controlled by the developer, including the developer's local system and Google Drive account.

OAuth credentials used by rclone are stored in an environment controlled by the developer.

5. Data sharing

Google user data accessed by this application is not sold, transferred, or shared with third parties.

6. Data deletion

Backup files stored in Google Drive can be deleted by the developer using Google Drive or rclone.

OAuth access can also be revoked through the developer's Google Account settings.

7. Security

Authentication is performed using Google OAuth 2.0. This application does not obtain or store the developer's Google Account password.

8. Changes to this policy

This Privacy Policy may be updated if the application's functionality or handling of Google user data changes.
